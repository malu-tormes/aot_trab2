# 🖥️ Usage Instructions

After uploading the program to the Arduino, you can test the 4-bit adder as follows:

1. **Provide two 4-bit binary numbers** through the circuit’s input pins.  
2. Observe the output on the **serial monitor** or on the LEDs connected to the board.  
3. The Arduino will display:  
   - The binary sum result.  
   - The **carry bit**, in case the result exceeds 4 bits.
