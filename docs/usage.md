# Usage

1. Connect push to buttons or switches to input pins 0-7.
2. Connect LEDs to output pins 8-12.
3. Power the Arduino board.
4. Input two 4-bit numbers using the buttons/switches.
5. Observe the output LEDs:
   
   - Pins 8-11: Result bits
   - Pins 12: Carry bit
6. Example:
 
   - Input 1: 1010
   - Input 2: 0101
   - Output: 1111 (sum), Carry: 0
7. To test, change inputs and verify the result.
